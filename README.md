# Rakindu Rajapaksha — Personal Portfolio

A modern, responsive developer portfolio built with **React + Vite** to showcase my projects, technical skills, and contact information.

🌐 **Live Portfolio:** [rakindu-rajapaksha.vercel.app](https://rakindu-rajapaksha.vercel.app)

## ✨ Highlights

- Responsive single-page portfolio
- Modern dark/light visual design
- Custom 3D developer illustrations
- Smooth Framer Motion animations
- About section with profile statistics
- Technology stack with real brand icons
- Featured projects with screenshots and project-detail modals
- GitHub repository links and live-demo support
- Contact form with client-side validation
- Email, phone, LinkedIn, WhatsApp, and GitHub integrations
- Downloadable CV
- Responsive navigation and Back to Top
- Desktop, tablet, and mobile support

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### UI & Animation
- Framer Motion
- Lucide React
- React Icons

### Deployment
- Vercel

## 📂 Portfolio Sections

- **Hero** — introduction, social links, CV download, and 3D developer illustration
- **About** — personal introduction, university information, development focus, and statistics
- **Skills** — technologies and development tools
- **Projects** — featured and additional projects with GitHub links and project details
- **Contact** — contact details and client-side contact form
- **Footer** — navigation, social links, WhatsApp, email, and Back to Top

## ⚙️ Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Clone

```bash
git clone https://github.com/Rakimnr/My-Portfolio.git
cd My-Portfolio
```

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Production build

```bash
npm run build
```
